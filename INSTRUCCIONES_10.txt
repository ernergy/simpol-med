PASO 1 — SUBIR A GITHUB
Reemplaza/sube la carpeta web de este ZIP.

PASO 2 — MARCAR TU USUARIO COMO ADMIN
En Supabase:
Table Editor -> profiles
Busca tu usuario.
En la columna is_admin cambia false a true.
Solo las cuentas con is_admin=true pueden abrir el panel de costos.

PASO 3 — CREAR web/.env.local EN TU COMPUTADORA
NO SUBAS .env.local A GITHUB.

Copia:
web/.env.local.example
como:
web/.env.local

Dentro pon:
NEXT_PUBLIC_SUPABASE_URL=https://djxexpekmkdjjqahrmis.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=la_misma_publishable_key_que_usa_android

La publishable key no es la clave secreta de OpenAI.
NO pongas OPEN_AI_KEY aquí.

PASO 4 — PROBAR WEB
En la terminal:
cd web
npm install
npm run dev

Abre:
http://localhost:3000

Ingresa con el correo y contraseña de tu usuario SIMPLE que marcaste is_admin=true.

PASO 5 — GENERAR DATOS
